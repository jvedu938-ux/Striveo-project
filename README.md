
# 🏆 STRIVEO – Project Management Platform

STRIVEO is a front-end project management platform that connects Partners,
Clients and Members in one place. It features a gold-and-dark themed UI,
role-based portals, and interactive dashboards built with pure HTML, CSS
and vanilla JavaScript.

## ✨ Features

### 🤝 Partner Portal
- Partner dashboard with project, client, earnings and completion stats
- Project management with search and status filters (Running / Completed / Pending)
- Client management: add, search and delete clients
- Payment management with revenue and pending-amount tracking
- Project report page with progress, payment summary and printable final report

### 👨‍💻 Member Portal
- Member dashboard with courses, progress and achievements
- Editable member profile (saved in localStorage)
- Membership plans: Basic, Standard and Premium
- Personal workspace with projects and tasks

### ⚙️ Common
- Settings page (profile, security, notifications, preferences)
- Fully responsive layout
- Data persistence using browser localStorage

## 🛠️ Tech Stack
- HTML5
- CSS3 (Flexbox, Grid, animations)
- JavaScript (ES6, DOM manipulation, localStorage)

## 📂 Project Structure
partner.html · partner-dashboard.html · project.html · client.html ·
payment.html · report.html · member.html · member-dashboard.html ·
profile.html · Membership.html · workspace.html · setting.html

## 🚀 Getting Started
1. Clone the repository
2. Open any `.html` file in your browser (start with `partner.html` or `member.html`)

## 📌 Note
This is a front-end only project; there is no backend yet.
